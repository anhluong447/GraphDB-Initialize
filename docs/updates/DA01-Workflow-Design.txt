  ⚠️  GHI CHÚ — COMMIT QUEUE:
  ─────────────────────────────────────────────────────────────────────────────
  Nếu developer push code TRONG LÚC first run đang chạy:

    Developer push code
          │
          ▼
    Git hook chạy bình thường → graph được update
          │
          ▼
    Commit được ĐƯA VÀO QUEUE, chưa gửi webhook
          │
          ▼
    Khi nhận POST /api/first_run/complete
          │
          ▼
    Flush queue → gửi webhook cho từng commit theo thứ tự thời gian
  ─────────────────────────────────────────────────────────────────────────────


================================================================================
  WORKFLOW 2 — TRANSITION (First Run → Ongoing)
================================================================================

  [Team Auto-Test Agent]          [Knowledge Base Server]
         │                                  │
         │  POST /api/first_run/complete    │
         │  { generated_count: 342 }        │
         │ ───────────────────────────────► │
         │                                  │  kiểm tra: 342 == total_functions?
         │                                  │
         │                           YES ───┤  set mode = ONGOING
         │                                  │  lấy danh sách queued commits
         │                                  │
         │  Webhook cho commit 1            │
         │ ◄─────────────────────────────── │
         │  Webhook cho commit 2            │
         │ ◄─────────────────────────────── │
         │        ...                       │
         │                                  │

  ⚠️  EDGE CASE — GEN FAIL MỘT SỐ FUNCTION:
  ─────────────────────────────────────────────────────────────────────────────
  generated_count < total_functions?

  → Vẫn chuyển sang ONGOING
  → Các function chưa gen được đánh dấu has_test = false
  → Khi commit tiếp theo touch function đó → gen lại
  ─────────────────────────────────────────────────────────────────────────────
